# UWEC Cybersecurity Club Website - [Blugold.group](https://blugold.group)

A static Caddy website for our club.

---

## Development

Prior to starting, ensure you have Caddy and git installed. Then you can just run these commands:

```bash
git clone https://github.com/Blugold-Group/blugoldgroup_website.git
cd blugoldgroup_website
sudo caddy run
```
